With the old signature, reformatting JSON or changing the amount is rejected. A correctly signed update matches, but still requires independent business validation.

Apply this to an integration

  1. Capture the raw request body before parsing JSON.
  2. Verify the signature using your provider's documented format. OmniWallet uses HMAC-SHA512 and the x-omni-sig header.
  3. Keep a durable receipt inbox and make business updates idempotent. This page does neither.
  4. Validate the order, asset, network, amount and authoritative payment state before fulfilment. A matching signature does not mean paid.

What is OmniWallet?

OmniWallet is a crypto payment platform for merchants and developers, with payment links, hosted checkout, an API and POS. One receiving address supports multiple supported EVM networks. Availability depends on supported networks, assets, accounts and markets.
