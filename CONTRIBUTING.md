# Contributing

Run `npm test` with Node.js before proposing a change. Keep the lab offline and the Postman collection read-only with a sandbox default. Document which behavior was actually tested.

Use synthetic fixtures only. Do not submit customer records, wallet keys, tokens, credentials or actual payment histories. Describe reproduction steps rather than attaching sensitive logs. Product enquiries can go to service@ewin888.com.

Do not add promotional link lists, competitor comparisons, guaranteed payment claims or untested provider compatibility. This is an educational example project, not a production SDK.
